# hex-editor

A Swing `HexEditor` component, plus a small demo application showing how to use it.

This is a very old project, recently pushed to GitHub by request for preservation
purposes. It is not under active development. The build tooling and code are being
modernized (e.g. migrating from Ant to Gradle) to keep the project maintainable and
buildable, not because new features are planned.

## Modules

- `HexEditor` — the reusable Swing hex editor component.
- `HexEditorDemo` — a demo application that exercises the component.

## Building

```
./gradlew build
```
